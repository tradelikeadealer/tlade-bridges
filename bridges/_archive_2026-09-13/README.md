# Indicators before release 3.5 (13 September 2026)

The TradingView and NinjaTrader 8 indicators as published until 13 September 2026, kept here unchanged.
Release 3.5 refactored them (one name per level, wall flip on 5-minute closes, closed-bar breakouts,
confluence zones sized on the EM, alerts). If you need the previous behaviour, this folder and the
GitHub release `indicators-pre-3.5` are where it lives. No fixes will be made to these files.

Also here: `atas/` (GEX Dashboard source and the full `TLAdeBridgeATAS.dll` as shipped until 13 September 2026) and `motivewave/` (v1.3.4 source and jar). The release `indicators-pre-3.5` carries the same ATAS bundle zip and MotiveWave jar.
